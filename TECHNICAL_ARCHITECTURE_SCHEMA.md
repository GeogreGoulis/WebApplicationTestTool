## 0. Core Testing Framework

### Technology Stack

| Component | Technology | Version |
|-----------|------------|---------|
| **Browser Automation** | Playwright | ^1.40.x |
| **BDD Framework** | Cucumber | ^10.x |
| **Language** | TypeScript | ^5.x |
| **Runtime** | Node.js | ^20.x LTS |

### Supported Browsers

| Browser | Engine | Playwright Driver |
|---------|--------|-------------------|
| Chrome | Chromium | `chromium` |
| Firefox | Gecko | `firefox` |
| Safari | WebKit | `webkit` |
| Edge | Chromium | `chromium` (channel: msedge) |
| Opera | Chromium | `chromium` (channel: opera) |
